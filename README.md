# GaitLab 步态分析与骨骼动画回放系统

面向康复科的 Web 端步态分析工具：动捕设备导出的 BVH 不再只是关节角度表格，
而是可回放的 **3D 蒙皮骨骼动画**，并支持两次复诊的半透明叠加对比、关节曲线、
肌电时序与可打印的对比报告。纯 TypeScript + 手写 WebGL2 蒙皮 shader，无 3D 框架依赖。

## 功能与需求对应

| # | 需求 | 实现 |
|---|------|------|
| 1 | 各家 BVH 髋零位不统一，按静止站立帧重新标零 | `bvh/angles.ts` 从世界坐标重建骨段向量，自动检测静止帧并减去基线，不读厂家欧拉角 |
| 2 | 髋膝踝偏差按步态周期 % 画热力条 | `data/normative.ts` 常模曲线 + `charts/HeatBar.ts` 101 格周期热力条 |
| 3 | 肌电包络与关节角度同一时间轴 | `bvh/emg.ts` 整流+RMS+低通包络，`curvesView` EMG 与膝角同轴 |
| 4 | 关节曲线与动画时间同步 | 全局 `store.playTime` 单一时间轴，3D 与所有图表共享游标、可互相 seek |
| 5 | 两次复诊半透明叠加 | `renderer.ts` 双 Actor + alpha 混合，支持周期相位/绝对时间两种对齐 |
| 6 | 左右对称指数、支撑相占比、同龄常模 | `bvh/gait.ts` HS/TO 事件检测、Robinson 对称指数、年龄段常模 |
| 7 | 镜头跟随骨盆、地面网格参照 | `GaitRenderer` 骨盆平滑跟随 + 程序化地面网格 + 轨道镜头 |
| 8 | 对比报告带图片和数据表 | `data/report.ts` 含 3D 截图、曲线插图、指标表，可打印/PDF/导出 HTML+CSV |

## 核心技术

- **BVH 解析**：任意关节层级、任意通道欧拉序（ZXY/XYZ/YXZ 均验证）
- **前向运动学**：自己实现的列主序 mat4 数学库，逐帧求关节世界矩阵
- **角度解算**：骨段向量投影到剪辑级矢状面（由行进方向×重力确定的固定轴），
  有符号夹角 + 静止帧标零，与厂家通道顺序、零位约定完全解耦
- **GPU 蒙皮**：WebGL2 UBO 传 80 个骨矩阵，顶点着色器内双骨线性混合蒙皮（LBS），
  胶囊体/椭球程序化人体网格，自带骨权重
- **持久化**：IndexedDB 存患者档案、复诊会话（BVH 原文 + EMG）

## 快速开始

```bash
npm install
npm run dev        # 启动开发服务器 http://localhost:5173
```

生成示例数据（无需真实设备即可走完整流程）：

```bash
npm run gen-sample   # 在 sample/ 生成 初诊/复诊 BVH 与 EMG CSV
```

操作流程：**患者页建档 → 动捕载入页选患者、传 BVH(+EMG)、保存会话并设为主/对比
→ 动画回放/关节曲线/对比报告**。

## 精度验证（关键验收）

用**已知关节角度真值**的合成 BVH 端到端验证解算管线：

```bash
npm run validate   # 1° 阈值验收
npm run smoke      # 全管线冒烟测试
npm test           # 两者一起跑
```

验证用例覆盖：标准/XYZ/YXZ 旋转顺序、厂家零位偏置（髋±12°/膝±7°/踝±6°）、
50Hz 低采样率。当前结果：**六个关节角度逐帧最大偏差 0.000°，远优于 ±1° 要求**，
且零位偏置被重新标零完全消除。

> 说明：合成数据的脚在“支撑相”也随关节正弦联动（无地面接触 IK），
> 因此事件检测在合成数据上的支撑相占比偏低于真实常模；真实动捕中脚会踏实，
> 检测器基于足底高度迟滞阈值的几何原理对真实数据有效。角度精度不受影响。

## 目录结构

```
src/
  core/        数学库、领域类型
  bvh/         解析、FK、角度解算标零、步态分析、EMG 包络
  render/      WebGL2 蒙皮 shader、人体网格、跟随镜头渲染器
  charts/      时间轴曲线、周期偏差热力条
  data/        常模曲线、同龄常模、IndexedDB、报告生成
  ui/          五个页签视图与中央状态
  validation/  合成 BVH、1° 精度验证、冒烟测试、示例生成
```

## 浏览器要求

需支持 WebGL2（Chrome/Edge 90+、Firefox 90+、Safari 15+）。
