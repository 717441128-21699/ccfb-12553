# 输电线路弧垂三维校核工具

架空输电线路导线弧垂与净空距离的三维校核工具。TypeScript 严格模式 + 手写 WebGL2 渲染（无三维框架），
按**悬链线精确方程**逐档解算导线形状，覆盖高温、覆冰、大风三种气象工况，自动校核导线到地面、树木、房屋的
最小净空距离并在三维场景中标出违规点。

## 核心能力

- **精确悬链线解算**：双精度（Float64）全程计算，`η = c·cosh(ξ/c)`，不用抛物线近似；
  挂点参数用 `sinh(mid)=h/(2c·sinh u)` 解析解，弧垂、线长、张力均为闭式精确值。
- **三工况应力求解**：
  - 手册代表档距法（默认，状态方程 `σ − K/σ² = σ0 − K0/σ0² − αEΔt`，与审图依据一致）；
  - 精确无应力线长守恒法（悬链线解析积分 + Brent 求根，用于复核）。
- **大风风偏**：合成荷载方向构造风偏斜平面，导线在平面内仍为悬链线，三维映射保证精确穿过两挂点，
  风偏角 `η = atan(gH/gV)`。
- **荷载体系**：自重、覆冰圆环重、风压 `W0=v²/1600`，覆冰体型系数 1.2 / 无冰 1.1，支持分裂导线。
- **净空校核**：地形双线性插值查垂直距离；树木（树干圆柱 + 树冠球包络）、房屋（朝向长方体 OBB）
  做分段-图元三维最近距离；均匀空间哈希粗判保证线性工作量。
- **三维可视化**：地形曲面、线框杆塔、三相导线（按工况着色）、树/房、红色违规球 + 黄色距离连线，
  轨道相机（拖拽旋转、滚轮缩放）、工况切换、图层显隐。

## 指标达成

| 要求 | 实测 |
| --- | --- |
| 30 基塔 × 3 工况解算 ≤ 1s | 约 16–50 ms（29 档 × 3 相 × 3 工况 = 261 条曲线） |
| 含地形 + 135 障碍的解算+校核 ≤ 1s | 约 70–120 ms |
| 弧垂与设计手册误差 ≤ 1cm | 同公式独立实现逐项差 < 1e-9 m；精确悬链线与手册抛物线的方法学差异在设计档距内 < 1.5cm（精确解偏保守） |

## 数据导入

- **工程 JSON**：完整 `ProjectInput` 结构（见 `sample/sample-project.json`），含导线型号、塔位、工况、限值。
- **地形 XYZ/CSV**：每行 `x,z,y`（空格/逗号/Tab 分隔，`#` 注释），须构成等间距规则格网。
- **塔位 CSV**：表头 `id,x,z,groundY,h0,h1,h2,off0,off1,off2,isStrain`，三相挂点高度与横向偏移。

导入时做字段与数值范围校验，错误以中文信息提示并定位到具体字段。

## 目录结构

```
src/core/       物理解算层（无 DOM 依赖，可独立用于 Node 计算/服务端）
  catenary2d.ts   二维悬链线精确解（挂点参数、弧垂、线长、取点）
  loads.ts        自重/覆冰/风荷载与比载
  stateEquation.ts 手册状态方程 + 精确线长守恒求解
  roots.ts        Brent 求根器
  windPlane.ts    风偏平面基与三维坐标映射
  engine.ts       逐档逐相解算引擎、自适应折线加密
  clearance.ts    地形/树/房净空校核、空间哈希
  importer.ts     JSON/CSV 导入校验
  types.ts        全部领域类型
src/render/     手写 WebGL2（矩阵、着色器、几何构建、场景渲染器）
src/sample/     内置 30 基塔示例工程（含刻意布置的三类违规）
src/ui/         界面主控与样式
tests/          7 个测试文件 39 个用例
scripts/        示例生成与端到端校核脚本
```

## 关键工程约定

- **单位制**：应力 MPa、比载 MPa/m（=N/(m·mm²)）、截面 mm²，悬链线常数 `c=σ/γ`（米）；
  双精度计算到最后一步上传 GPU 才转 float32。
- **坐标**：X 沿线路走向、Y 高程向上、Z 横线路。
- **净空限值**按 GB 50545 110kV 常用值给默认，可在工程 JSON 的 `limits` 中整体覆盖。
